# 验证码识别助手

Chrome Manifest V3 扩展，当前版本为 **1.3.0**。在侧栏中框选或上传图片，在本机识别、核对并填写结果。

## 安装

1. 下载仓库 ZIP 并完整解压。
2. 打开 `chrome://extensions`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择本项目的 **extension** 文件夹。
4. 固定工具栏图标，打开需要使用的网页并点击插件图标。

升级时覆盖原目录，在扩展管理页重新加载，再关闭并重新打开侧栏。

## 使用

- **整图识别**使用随包提供的 ddddocr ONNX 模型，可选择大写字母与数字、大小写字母与数字、纯数字或全部字符。
- **单字符实验 · CNN＋宽高比**识别一个浅底深色的数字或大写字母，显示前三个候选。
- **单字符实验 · 加入内孔特征**对易混淆的 0/O 增加内孔特征。该选项在离线测试中有升有降。

点击“框选网页验证码”后拖动选框，核对或编辑识别结果，再点击“点选输入框填写”并选择网页输入框。单字符模式应只框选一个字符。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `extension/manifest.json` | 扩展声明及版本 |
| `extension/panel.*` | 侧栏界面 |
| `extension/background.js` | 侧栏启动及截图 |
| `extension/content.js` | 网页框选和填写 |
| `extension/ocr.js` | 整图 ONNX 推理 |
| `extension/glyph.js` | 单字符 CNN 与几何特征 |
| `extension/vendor/` | 本地推理依赖、模型和第三方许可 |
| `scripts/check.py` | 结构及 JavaScript 语法检查 |
| `scripts/package.py` | 构建安装 ZIP |

## 开发与打包

安装 Python 3.9 或更新版本、Node.js 18 或更新版本，然后在项目根目录运行以下命令。

```sh
python scripts/check.py
python scripts/package.py
```

输出文件位于 `dist/`，文件名带 manifest 中的版本号。扩展安装文件已包含模型及运行时，直接安装无需执行打包步骤。

## 数据与权限

图片在本机推理。网页截图通过 Chrome 会话存储临时传递，侧栏取得裁剪图后删除临时截图。首次在某个网站使用框选或填写时会申请网站权限。Chrome 设置页和扩展商店等受保护页面无法使用网页注入功能。

## 测试范围

单字符模型在 36 个归一化字符输入上与原 Python 推理对照，最高分预测全部一致，分数最大绝对差小于 0.000006。Canvas 图片输入、空白图片报错及两个单字符模式经过 Node 环境检查。

完整 Chrome 安装、框选与填写的端到端验证尚待完成。浏览器 Canvas 缩放与原训练脚本 Pillow LANCZOS 存在实现差异，离线准确率不能直接作为插件准确率。实验模型覆盖 0–9 和 A–Z，彩色干扰、旋转、点阵或重叠字形可能导致误判。
