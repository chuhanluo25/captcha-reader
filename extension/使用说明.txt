验证码识别助手 · Chrome 离线版 1.3.0

安装
1. 解压整个 ZIP，保留 vendor 文件夹。
2. 在 Chrome 地址栏输入 chrome://extensions 并回车。
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择包含 manifest.json 的 captcha-reader 文件夹。
5. 点击工具栏的拼图图标，将「验证码识别助手」固定到工具栏。

使用
1. 打开登录网页，再点击工具栏的插件图标，右侧会出现操作面板。
2. 点击「① 框选网页验证码」，首次使用时在 Chrome 弹窗中允许访问当前网站，再在网页中按住鼠标左键拖出一个矩形。
   只框验证码图片，尽量避开外边框及旁边的文字；松开后开始识别。
3. 核对结果。需要时可修改结果，或切换「字符范围」后重新识别。
4. 点击「② 点选输入框填写」，再点击网页的验证码输入框。
   也可以点击「复制结果」后手动粘贴。
5. 自行点击网页的登录按钮。

识别能力与限制
- 模型及推理引擎都已打包，安装后不需要联网下载，不需要 API 密钥或额外服务。
- 默认识别大写字母和数字，可切换大小写字母、纯数字或不限。
- 这是通用模型，没有针对你的目标网站专门训练；彩色干扰、点阵字、旋转和重叠可能导致误识别。
- 对你提供的截图裁剪测试，模型给出的候选结果为 PTHRB。该结果未得到网站验证，不能视为标准答案。
- 不能保证所有验证码准确；刷新验证码后，需要重新框选。
- 可以识别当前屏幕显示的 img、Canvas、背景图或内嵌框架中的验证码。
- 点选填写仅覆盖当前网页主框架，内嵌框架中的输入框请复制后粘贴。
- Chrome 设置页、扩展商店等受保护页面不能注入框选工具。
- 建议 Chrome 116 或更新版本。首次识别可能需要几秒，取决于电脑性能。
- 访问新网站时会请求该网站的可选访问权限；tabs 权限用于读取当前页面地址以确定授权范围。
- 点击工具栏插件图标取得当前页的临时截图权限；切换网站后请再次点击插件图标。
- 如果侧栏打开但不能框选，请先点击验证码所在网页标签页，再点击工具栏插件图标。

数据处理
- 只在你框选时截取当前可见页面；裁剪出的图片在本机运行识别。
- 截图临时放在浏览器会话内存中，侧栏取得裁剪图后删除临时截图；不会写入同步存储。
- 不读取或保存账号密码，不上传图片，不自动提交登录。

验证记录
- JavaScript 语法检查通过。
- 附带的 ONNX Runtime Web/WASM 在 Node 测试环境中成功加载模型并推理截图裁剪。
- CTC 解码的重复字符、空白分隔检查通过。
- 当前执行环境无法启动完整 Chromium，尚未完成真实浏览器端到端安装、框选、填写测试。

源码均包含在本目录中；第三方依赖和许可见 THIRD_PARTY.md 与 vendor。

1.0.1 更新
- 修复框选时 Cannot access contents of the page / host permission 报错。
- 框选和填写前申请当前网站权限；拒绝授权时显示具体提示。
- 工具栏点击显式打开侧栏，以获得 activeTab 临时截图权限。
- 更新方法：关闭旧侧栏，解压新版覆盖原文件，在 chrome://extensions 点击插件卡片的重新加载按钮，刷新登录网页，再点击工具栏插件图标。如被停用，请按 Chrome 提示重新启用。
- 授权、拒绝授权、已授权及受保护页面分支已通过模拟 API 回归检查；真实 Chrome 端到端验证仍待完成。

1.1.0 更新
- 识别后显示易混字符的位置和可替换字符，可逐位修改，再复制或填写。
- 「放大原图」以两倍原尺寸显示截图，可横向滚动查看细节。
- 提示依据字形和所选字符范围，不代表模型置信度。

1.2.0 更新
- 新增按识别结果显示的核对提示：9 可核对 G，3 可核对 B，C 可核对 G，6 和 G 可互相核对。
- 点击「撤销上次替换」可逐步撤销本轮按钮替换。手动输入或重新识别会清除旧记录。


1.3.0 更新
- 集成 glyph_cnn_benchmark 的增强 CNN、宽高比辅助参数和可选内孔特征。
- 选择“单字符实验”后，只框选或上传一个浅底深色的数字或大写字母。显示前三个候选，最高分写入可编辑结果框。
- 实验模型只支持 0–9、A–Z，单字符模式固定使用这 36 类；字符范围选项在整图模式生效。
- 整串图片请使用“整图识别”。单字符模式需要用户自行框选字符。
- 内孔特征在独立测试中有升有降，可按需比较两个实验选项。
- 浏览器通过 Canvas 等比例缩放到 32×32；训练脚本使用 Pillow LANCZOS。两种缩放实现可能导致预测差异，离线实验准确率不能直接当作插件准确率。
- 单字符推理由本机 JavaScript 执行，模型参数随包提供。

1.3.0 验证记录
- 36 个字符的归一化输入上，JavaScript CNN、宽高比和内孔分数与 Python 对照一致，最大绝对差小于 0.000006，全部首选预测一致。
- Canvas 图片输入、空白报错、模型本地加载和两个单字符模式已通过 Node 环境检查。
- Chromium 启动被执行环境的 socket 权限限制，真实 Chrome 安装、框选与填写的端到端验证尚未完成。
- 对角线与轮廓角度实验的验证集选定权重为零，其分数贡献已等效包含在宽高比模式中。
